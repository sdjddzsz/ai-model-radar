🧭 AI 模型雷达 · 使用说明
========================================

【怎么打开】
双击桌面上的「AI模型雷达」即可。
它会自动启动本地数据服务（最小化窗口），然后在你的默认浏览器里打开面板。

【怎么关闭】
· 关掉浏览器标签页只是不看面板，服务还在后台跑（不耗什么资源）
· 想彻底停掉：关掉任务栏里那个最小化的「AILens」命令行窗口

【面板里有什么】
1. 排行榜 —— 开源热度榜（真实下载/点赞）、性价比榜（每百万 token 价格）、
   最新上线、官方跑分榜入口、模型梯队速查
2. 模型库 —— 400+ 模型，可按 开源/闭源、厂商、免费、推理、视觉、工具调用 筛选。
   点开任何一个模型能看到：详细价格、上下文长度、知识截止时间、
   擅长什么、推荐搭配什么客户端、去哪用
3. 客户端怎么选 —— 8 种典型场景的最佳组合、14 个客户端 × 10 类模型的支持矩阵
4. 趋势动态 —— 模型动向雷达（从最新资讯自动统计哪家动作多）、
   多源资讯流、最近冒头的开源模型、实验室仓库发布记录
5. 免费接口 —— 7 家聚合/路由厂商的 API 端点速查 + 免费模型实时列表
6. 使用方案 —— 按你的任务画像，结合实时价格算出路由表 / 月度成本 / 兜底方案

【数据说明】
· 数据源：OpenRouter（模型/价格）、Hugging Face 镜像（开源热度）、
  GitHub Releases、多源 RSS 资讯
· 缓存放在 AILens\cache，断网时自动用上一次的数据，右上角会提示「缓存」
· 想强制更新就点右上角「刷新数据」
· 官方能力跑分榜（LMArena 等）本机网络访问不到，程序里不放伪造的分数，
  提供了浏览器直达按钮

【自动更新】
· 双击图标后，服务先起来、再在后台自动拉一次最新数据（约 5–20 秒）。
  这期间打开面板会显示「正在更新数据…」，等这一次抓完 —— 不会重复抓两遍。
· 默认策略 stale：上次抓取超过 10 分钟才重抓（避免反复重启白跑流量）。
  想每次启动都重抓 → 在「AI模型雷达.cmd」里把 `set AILENS_START_REFRESH=always` 前面的 rem 去掉。
· 服务开着期间，每 6 小时自动重抓一次；右上角显示「自动更新 · 每 6 小时 · 下次 03:46」。
  改间隔：set AILENS_AUTO_HOURS=3（设 0 = 只靠启动那一次）。
· 右上角「↻ 刷新数据」仍然是手动强制重抓，一直有效。
· （开机自启的脚本已按你的要求删掉了 —— 不让它随系统起来，只在你双击时才跑。）

【「使用方案」页会不会自动更新】
· **会的一半**：价格 / 路由表 / 月度成本，全部跟着实时数据重算。
  页面每 5 分钟自己查一次（只在页面可见时），发现服务端有新数据就自动重渲染，
  右下角闪一条「✓ 数据已自动更新」，并保住你当前的滚动位置 —— 不用手动点刷新。
· **不会的一半**：「任务画像」（那 13 类任务的构成）是**按本机工作日志人工标定**的，
  写在 profile.local.mjs，机器不会自己去读你的日志重新归纳。
  - 改完该文件 **不用重启服务**了（按文件修改时间热加载，页面 5 分钟内自动跟上）；
  - 画像超过 **7 天**没重新采集，使用方案页顶部会挂一条橙色提醒条。
  - **界面里就能做（推荐）**：「使用方案」页 ① 本机任务画像卡里有三个按钮 ——
      🗂 备份当前画像 / 👀 预览重算结果（先看对比表，再决定写不写）/ ↩ 还原到某份备份。
      备份都放在 `AILens\backups\`，带时间戳，不用再去文件夹里翻 `.bak`。
      还原时会自动把当前这份存档，不会出现"还原错了回不去"。
  - **也可以在文件夹里双击** `AILens\重算画像.cmd`。它扫近 14 天的工作日志
    和 output 产物，重新分配各任务的日均调用次数（先打印对比让你确认，再问你要不要写入；
    旧文件自动备份为 profile.local.mjs.bak）。
    ⚠️ 它只更新「用量 + 证据」，**能力需求向量（上下文 / 工具 / 推理 / 视觉 / 隐私 /
    省钱权重）不会动** —— 那些是人工标定的，机器判断不了，要改就直接编辑
    profile.local.mjs。

【文件位置】
AILens\
  ├─ run.cmd            启动入口（Windows 双击，自适应路径）
  ├─ server.mjs         数据服务（Node 22，零依赖，含自动更新逻辑）
  ├─ start.mjs          启动器逻辑
  ├─ public\index.html  面板界面
  ├─ profile.example.mjs 任务画像示例
  ├─ profile.local.mjs  你自己的任务画像（不会被 git 提交）
  ├─ 安装开机自启.cmd   登录后自动起服务并自动拉数据（可撤销）
  ├─ 取消开机自启.cmd   删除上面那个启动项
  └─ cache\             数据缓存

想把 run.cmd 放到桌面？在它上面右键 → 发送到 → 桌面快捷方式即可。
